# Project Guidance

## ShambaCare

Agritech web application providing practical crop-growing guidance for Kenyan farmers.

### Architecture & Tech Stack

- **Framework**: TanStack Start (React 19 + Vite)
- **Styling**: Tailwind CSS v4
- **Routing**: File-based routing in `src/routes/`
- **Data**: Crop information in `src/data/crops.ts`

### Guidelines

- Keep code modular and strictly typed.
- Maintain responsive and accessible UI components.
