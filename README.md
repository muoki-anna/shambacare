# ShambaCare

Practical crop growing guidance and agricultural intelligence platform for Kenyan farmers.

## Features

- **Major Crops Guidance**: Comprehensive guidance covering maize, tea, coffee, beans, potatoes, tomatoes, bananas, wheat, and more.
- **Agronomic Details**: Ecological requirements (altitude, rainfall, soil pH), land preparation, planting, fertilizer regimens, pest and disease management, harvesting, and yield potential.
- **Market Insights**: Market channels, pricing indicators, value-addition opportunities, and post-harvest handling advice.
- **Responsive Interface**: Clean, accessible mobile-friendly interface designed for farmers and extension workers.

## Tech Stack

- **Framework**: TanStack Start (React 19)
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Type Checking**: TypeScript

## Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- npm, pnpm, or bun

### Installation

```sh
npm install
```

### Development Server

```sh
npm run dev
```

### Build

```sh
npm run build
```

### Run Tests

```sh
npm run test
```
